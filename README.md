# 🎮 Simon Game

A fun and interactive Simon Says memory game built using HTML, CSS, and JavaScript.

## 🚀 Features

- Interactive color buttons
- Random sequence generation
- Level-based gameplay
- Game over detection
- Mobile-friendly design
- Start button for mobile users

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How to Play

1. Click on the START GAME button.
2. Watch the color sequence carefully.
3. Click the buttons in the same order.
4. Each level increases the difficulty.
5. If you click the wrong button, the game ends.

## 📱 Responsive Design

The game works on desktop and mobile devices.
